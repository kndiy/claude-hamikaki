# khiem_nguyen

Created 2026-11-06 by the launcher.

## Purpose and goals
Track the health checkups of Nguyen Duy Khiem (born 02-01-1991, male) over the years.
Goal: one Excel report (.xlsx) that monitors results across years, with time stamps (sample/collection date per checkup), so trends are visible.
Currently only 2026 data exists (from the file below).

## Tech stack and key dependencies
- Deliverable: `health_report.xlsx`, generated by a script.
- Python 3 in a project-local venv `.venv/` (made with `uv`, because `python3 -m venv` fails here: python3-venv is not installed). Dependency: `openpyxl` 3.1.5 (`requirements.txt`).
- `pdftotext` (poppler-utils) extracts the text from the lab PDFs. The PDFs have a real text layer.

## Structure and key files
- `<year>/<month>/` holds the source lab reports (PDF), e.g. `2026/11/`.
- `2026/11/NGUYEN DUY KHIEM_061126-503581_Ver1-signed.pdf`: 4-page signed lab report from Hoan My Sai Gon Hospital (company checkup, RND2B).
  - Sample date 06/11/2026 (blood received 09:02:14, urine 08:59:17); printed 06/11/2026 13:07.
  - Sections: haematology (full blood count), biochemistry/immunology, urine analysis. Page 3 is blank.
  - Each result has a reference range, unit and an out-of-range flag (bold in the PDF).
  - Out of range in this report: MCHC 316.0 (low), Cholesterol 5.76, HDL 0.84 (low), LDL 4.36, Non-HDL 4.92, Chol/HDL 6.86, LDL/HDL 5.19 (all high), urine S.G 1.004 (low). Read from the PDF image on 2026-11-06, so re-check against the PDF before relying on them.
- `health_report.xlsx`: generated, do NOT hand-edit (it is rebuilt from the PDFs on every run). Sheets:
  - `Summary`: one row per test, one column per checkup date, formulas into `Data`. Out-of-range values are shaded (red = high, blue = low). The test name links to its row in `Tests`.
  - `Data`: long format, one row per result (date, time received, test, result, unit, reference, low/high, flag, source PDF). Filterable.
  - `Tests`: glossary with what each test measures and what high/low can mean. Generic information only, not medical advice. Written from general knowledge, not from a source document, so treat it as a starting point.
  - `Charts`: line charts for the tests marked "Charted" (about 15). With one checkup they show a single point.
- `scripts/build_report.py`: parses all `<year>/<month>/*.pdf` and rebuilds the workbook.
- `scripts/tests_dictionary.json`: per-test display name, category, explanation, and whether it is charted. Keyed `SECTION/printed name` (HAEM, BIO, URINE), because names like Glucose and Bilirubin appear in both blood and urine.
- `requirements.txt`, `.venv/`: Python environment (the `.venv` can be deleted and recreated).

## Commands (build / run / test / lint)
- Set up once: `uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt`
- Build the report (from the project root): `.venv/bin/python scripts/build_report.py`
- Adding a new checkup: put the PDF in `<year>/<month>/`, run the build. If the script stops with "UNKNOWN tests", add those entries to `scripts/tests_dictionary.json` and rerun.
- No automated tests or lint. After a build, spot-check values against the PDF.

## Conventions, constraints, decisions
- Source PDFs go in `<year>/<month>/`, keeping the original file name.
- The lab's reference ranges differ between labs and may change between years, so store the reference range and unit with each result, not just the value.
- Health data is personal. Keep it local in this folder only. Don't upload it to external services or share it.
- Decided 2026-11-06: long `Data` sheet as the single source, wide `Summary` built from it with formulas, plus a `Tests` glossary sheet. The "pivot" is the formula-based Summary, not a real Excel PivotTable (openpyxl cannot create those).
- Flags (HIGH/LOW) are computed by the script from the printed reference range, not read from the PDF's bold text. For the 2026 report this gave exactly the 8 bold values.
- Test names are English, as printed on the report, with a cleaner display name. Vietnamese sub-names (e.g. Bilirubin Toàn Phần) are shown in English.
- All 64 results are kept in `Data`. Only about 15 tests are charted.
- Text results (urine `neg`, `norm`, colour) are stored as text and not charted. HBsAg is stored as its number (0.32) with the word "Nonreactive" in the Qualifier column, so the Summary shows 0.32 only.
- Limitation: the LibreOffice here has no Calc component, so I could not open the workbook in a spreadsheet app. I checked the formulas and links by script only. Open it in Excel once to confirm it displays correctly.

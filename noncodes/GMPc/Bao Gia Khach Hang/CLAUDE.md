# Bao Gia Khach Hang (group)

Rules here apply to every project below this folder. Put project-specific rules in that project's own CLAUDE.md.

## Scope
Customer quotations (bản chào giá) from GMPc. New quotes are made with the tool in `Chao gia GMPc\` (see its CLAUDE.md). `2025 Mau chao gia\` holds the company's master templates.

## Shared rules
- `2025 Mau chao gia\` is read-only source material. Never edit, rename or delete files there.
- **Row heights in a quote** (user, 2026-10-13): in the content block (row 15 down to the "Tổng cộng bao gồm thuế GTGT" row), set the height by the number of wrapped text lines: 1 line = 30, 2 lines = 35, 3 lines = 50. For more than 3 lines, add 15 per extra line; this part is an assumption pending confirmation.
- Claude never sets prices. Prices come from the user for each quote.
- Don't put wording in a quote that could read as payments to authorities ("chi phí ngoại giao", "thúc đẩy hồ sơ", "chi phí tiếp đoàn").
